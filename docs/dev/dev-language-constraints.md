# 语言约束：三种宿主语言

这个项目同时被三种语言执行：脚本本体是 **Node**，启动器是 **VBScript**，
入口与流水线是 **cmd 批处理**。本文列出各自的硬约束——
这是最容易写出"看着对但跑不了"的地方。

静态门禁能拦一部分，但**不是全部**：有些问题只有在真跑时才暴露。

## 1. 脚本本体：现代 Node，但编排层限 ES3

| 范围 | 约束 |
|---|---|
| `atomic/`、`workflows/` 的入口、`session/` | 可以使用现代语法 |
| **`orchestration/` 的共享 main 与驱动的共享部分** | **只用 ES3 子集** |

为什么编排层要退到 ES3：**那份共享代码与另一套实现共用**，
而那边的脚本语言只到 ES3。所以这一层的禁词是：

| 不能用 | 替代 |
|---|---|
| `let` / `const` | `var` |
| 箭头函数 | `function` |
| 模板字符串 | 字符串拼接 |
| `Object.keys` | `for-in` + 判断自有属性 |
| `JSON.` 系列 | 手写拼接与解析 |

**门禁会扫描编排层与共享源码的这套禁词**，写错了会在提交前被拦下。

> 另一套实现里**全部脚本**都受这套限制。所以"那边不能用现代语法"这条结论，
> 在本栈只对编排层成立。

## 2. 编码与行尾

- `.js` / `.vbs` / `.bat` **一律 ASCII**：中文只写进 `.md`。这条与另一套一致，
  原因不是语言限制，而是**避免跨编辑器/跨区域设置出现不可见差异**。
- 行尾：`.bat` / `.vbs` / `.conf` 必须 CRLF；`.js` / `.md` / `.ps1` 必须 LF。
  用编辑器默认可能写成 LF，而 **cmd 会把 LF 结尾的注释行当命令执行**。

## 3. 启动器：VBScript

- 启动器用对话框问参数；**完成提示也是弹窗**——在没有焦点、也没有人点的会话里会一直等；
- 对话框被取消时按失败处理（取消 = 什么都没做）；
- 拼命令行时要注意给含空格的参数加引号；
- 失败原因显示在弹窗里，所以自动化场景应直接调 `.js`。

## 4. 入口与流水线：cmd 批处理

| 约束 | 后果 |
|---|---|
| 调用另一个 `.bat` 必须写 `call` | 漏了会**静默结束**后续步骤，而退出码仍然成功 |
| 延时要与判定方式配合地写 | `timeout` 在标准输入被重定向时会跳过延时；用 `ping` 更稳 |
| 行尾必须是 CRLF | LF 结尾的注释行会被当命令执行 |
| 变量展开时机 | `%变量%` 在命令执行前展开；读退出码要在**下一行**读 |

## 5. PowerShell 里拼 `cmd /c` 的坑（本栈特有）

本技术栈**允许**把含 `=` 与空格的表达式直接写在命令行上，但这在 PowerShell 里会出问题：

```powershell
# 危险：PowerShell 先解析一遍引号，cmd 拿到的东西可能已经不是你想给的
cmd /c "`"%RUN%`" script.js `"a = 1`""
```

三个稳妥做法：

1. 直接用 `cmd` 执行 `.bat`（CI 里推荐）；
2. 用 PowerShell 的调用运算符配合数组传参，而不是拼一个字符串；
3. 把值放进环境变量（`CCS_EVAL_EXPR` / `CCS_WRITE_EXPR` / `CCS_SYMBOLS`）。

## 6. 谁负责拦什么

| 语言 | 门禁能自动拦的 | 只能靠人的 |
|---|---|---|
| 脚本本体 | 语法检查、ES3 禁词（仅共享层）、编码、行尾 | 语义错误、接口名写错 |
| 启动器 | 编译检查 | 对话框排版、文案是否清楚 |
| 批处理 | 行尾、编码 | `call` 漏写、`timeout` 误用、PowerShell 引号（**只有真跑才暴露**） |

## 7. 三条来自实践的提醒

1. **改 `.vbs` 之后要真的跑一次**：纯语法检查看不出运行期才会解析到的东西。
2. **批处理的两个坑不能靠静态检查发现**：`call` 漏写与 `timeout` 误用都会"看起来成功"。
   改动这类文件后，**用一次真实调用验证**。
3. **参数里的特殊字符**：只有真的跑一遍才知道 PowerShell 会不会吃掉引号。相关处置见
   [`../reference/ref-decision-tables.md`](../reference/ref-decision-tables.md) 表 3。
