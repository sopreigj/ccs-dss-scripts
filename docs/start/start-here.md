# 这个项目是什么

## 一句话

把 CCS 的调试动作变成**能从命令行调用、能写进流水线**的脚本，让"烧录—运行—读回—判定"
这套循环不再需要有人在 GUI 里点。

## 它解决的具体问题

用 CCS GUI 调一次目标是这样的循环：打开工程、等索引、连目标、烧录、跑一段、停机、找到变量、
把值抄下来、关掉。每一步都要人手参与，而且**没有一步能被流水线复用**。

这个仓库把每个动作切成一个可以独立运行的命令，于是：

- 一次连接就能完成"烧录 → 运行 → 停机 → 读值"，机器可读；
- 失败有明确的判据（结果标记行），不需要人看日志猜；
- 可以把几十次调试串成一个 `.bat` 或一条 CI 任务。

## 三个层次怎么分工

```
atomic/         一层：一次调用做一件事，各开一个会话
workflows/      一层：一个会话内连续做几步（跨会话的状态不保持，所以必须写在一起）
orchestration/  一层：会话内的动作序列，与具体技术栈无关
```

选择规则只有一句：

- **这件事单独跑有意义** → 用 `atomic/` 里的脚本。
- **需要连续动作、且中间状态活在会话里**（写完变量再运行、跑到断点、单步、观察点、采样）
  → 用 `workflows/`。**跨脚本传状态是不成立的**，这不是风格问题：符号表、断点、单步位置、
  外设配置都是会话的子对象，会话一关就没了。

## 你（使用者）站在这一层的上面

上面这三层都是**给你的工具**，不是给你住的房子。**你自己那一层不在这个仓库里**——
它是你的命令行、你的 `.bat`、你的 CI 任务，或者你的 AI 助手。

```
        你（或你的 CI、你的 Agent）      ← 你的层：在仓库之外
   ┌──────────────┴───────────────┐
atomic/…js                    workflows/…js   ← 你的两个入口
   └──────────┬───────────────────┘
              ▼
   orchestration/ + session/                   ← 仓库内部实现，你不用直接碰
```

所以"我要干一连串活"通常**不是"再写一个编排层"**，而是：先看能不能用现成的
`atomic/` / `workflows/` 拼出来，再决定你自己的脚本放在哪、叫什么。

**完整做法（该用什么、能不能拆、放哪、叫什么）见
[`../guides/gu-compose-your-own.md`](../guides/gu-compose-your-own.md)。**

## 能做什么

- 烧录固件、校验目标内容与固件文件是否一致；
- 控制运行：连接、运行、运行 N 毫秒后停机、停机、复位、报告目标状态；
- 读写内存、填充、导出、导入；读写 CPU 寄存器；
- 求值表达式、给表达式赋值（需要符号表）；
- 单个会话内：加载后运行、跑到断点、单步、写后读、定间隔采样到 CSV、驱动空闲引脚；
- 维护 flash：列出目标支持的 flash 操作、按操作名执行、在同一会话内改写该操作使用的属性。

## 明确不做什么

- **不做安全控制**：脚本退出时释放目标，目标会继续自由运行固件。确定停机的手段是断电或
  固件自身的停止逻辑。这不是安全系统。
- **不猜**：参数写错、地址缺 `0x`、路径不存在，一律报用法错误并退出，不替你补默认值。
- **不假装成功**：失败必须给出非零退出码或失败标记行，并带上原因。
- **不做跨会话的状态延续**：做不到就不假装能做到，需要连续动作就写成一个脚本。
- **不碰加密线**：写 CSM 密码的操作被主动拒绝（详见
  [`../reference/ref-scripts.md`](../reference/ref-scripts.md) 的 `flash_op` 一节）。

## 边界与未确证的结论

使用前请分清三类结论，文档里对它们有明确标注：

| 类别 | 含义 |
|---|---|
| **实测** | 在本项目的开发环境（CCS 12.2.0 + 一块 C2000 板 + XDS100 系列仿真器）上真跑过，有复现命令 |
| **文档级** | 来自官方接口文档或参考手册，未在本项目环境复现 |
| **未确证** | 至今没有可靠证据，**不要当结论用** |

未确证项的清单集中在
[`../reference/ref-api-dss.md`](../reference/ref-api-dss.md) 的"未确证"一节。
**"未确证"不等于"不可用"，也不等于"板子没接"**——它只表示没人量过。
