# 术语与受控词汇

**一个概念只有一个名字。** 本项目把这个当作硬规则：同一个动作在脚本名、函数名、文档里用同一个词，
避免"看着差不多但不是一个东西"的混乱。新增脚本前先查这张表。

用法：表里"**不要用**"一列的词，如果出现在代码或文档里，就是需要改掉的地方。

## 会话与运行控制

| 用 | 不要用 | 含义 |
|---|---|---|
| **会话**（session） | `连接`（当名词用） | 一次调试连接的完整生命周期：打开、连接、操作、释放。**会话是状态的边界** |
| **连接**（connect） | `打开`、`挂上` | 会话内与目标建立通信这一步 |
| **释放**（release） | `关闭会话` 混用 | 会话结束时断开并让目标自由运行 |
| **停机**（halt） | `停`、`stop`、`暂停`、`挂起` | 让 CPU 停下来。**不要**用 `stop`——它容易被理解成"停止调试" |
| **复位**（reset） | `重启`、`restart` | 把目标复位。默认复位的落点**不是**程序入口 |
| **运行**（run） | `跑`、`启动` | 让 CPU 继续执行 |
| **装载**（load program） | `下载`、`烧录` 混用 | 把固件放进目标。**只放进去，不运行** |
| **烧录**（flash） | — | 把固件写进**非易失**存储。与"装载到内存"是两件事 |
| **校验**（verify） | `检查` | 只读地比对目标内容与固件文件是否一致 |

## 目标与状态

| 用 | 不要用 | 含义 |
|---|---|---|
| **目标**（target） | `板子`、`芯片`（当同义词用） | 被调试的对象整体。板子与芯片是它的组成，不是同义词 |
| **目标配置**（target configuration） | `ccxml 文件`（当术语用） | 决定"用哪个仿真器、连哪个芯片"的配置文件 |
| **仿真器**（emulator / probe） | `下载器`、`探针` 混用 | 连在主机与目标之间的调试硬件 |
| **程序计数器**（PC） | `指针` | CPU 当前执行位置 |
| **停机**（halted） | `暂停状态` | 目标的"CPU 已停住"这一状态 |

## 判定与输出

| 用 | 不要用 | 含义 |
|---|---|---|
| **结果标记行**（result marker） | `成功标记`、`OK 行` | stdout 上恰好一行的 `CCS12_2_0_RESULT=OK` / `=FAIL <原因>` |
| **失败标记** | `错误码`、`错误信息` | 上面那一行的 `FAIL` 形式。**原因只在这里** |
| **成败** | `返回值` | 这件事是成功还是失败。判据只有标记行 |
| **哨兵**（sentinel） | `标记`、`校验值` | 装载共享库之后断言的一个字符串常量，用来确认"真的装进来了" |
| **引导块**（bootstrap block） | `引导代码`、`头部` | 每个脚本开头那段**逐字相同**的代码 |
| **用法错误** | `参数错误` | 参数形状不对导致的失败：报错 + 打印用法 + 退出 |
| **拒绝**（refuse） | `禁止`、`拦截` | 脚本在动手之前主动不做某个操作，并说明理由 |

## 脚本组织

| 用 | 不要用 | 含义 |
|---|---|---|
| **原子脚本**（atomic script） | `基础脚本`、`单脚本` | `atomic/` 下"一次调用做一件事"的脚本 |
| **工作流**（workflow） | `流程`、`组合脚本` | `workflows/` 下"一个会话内连续做几步"的脚本 |
| **编排层**（orchestration layer） | `框架层` | `orchestration/` 下与具体技术栈无关的共享实现 |
| **共享库**（shared library） | `公共库`、`工具库` | `session/` 下被脚本装载的库；**不被直接调用** |
| **启动器**（launcher） | `包装器`、`图形接口` | 与 `.js` 同名的 `.vbs` 文件 |
| **判定原语**（verdict primitive） | `包装脚本` | 把任意一步翻译成一行判定的那个 `.bat` |
| **配置键**（configuration key） | `配置项`、`字段` | 配置文件里的一个键 |
| **覆盖链**（precedence chain） | `优先级`（单独用） | 某个键、某个入口的完整取值顺序。**按键、按入口分别成立** |
| **只读启动器** / **改状态启动器** | `安全的` / `危险的` | 无人值守模式下是否允许采用默认值的分类 |
| **空闲引脚** | `可用引脚` | 复用配置为通用且外部没有接线的引脚 |

## 容易混的三对词

| 对 | 区别 |
|---|---|
| **停机** vs **释放** | 停机是"让 CPU 停"；释放是"断开连接"。释放后目标会自由运行——所以"停机"有效范围只在本次会话内 |
| **装载** vs **烧录** | 装载是把固件放进目标（可能是易失存储，重启就没了）；烧录是写进非易失存储。两者是不同的操作 |
| **校验** vs **读回** | 校验是脚本自己比对目标与文件并给出判定；读回只是把你写的值打印出来，判定由你自己做 |
